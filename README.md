# 日語隨身通 Nihongo Go — 零基礎到日常對話 & JLPT N5~N1 隨身日語學習 APP

專為**日文零基礎學習者**打造的手機優先（Mobile-First PWA）日語學習應用程式，設定兩大核心目標：
1. **短期目標（開口簡單對話）**：從五十音字源聯想口訣出發，快速掌握自我介紹、餐廳點餐、車站問路、購物免稅、飯店入住與交友閒聊。
2. **中長期目標（JLPT N5 ➔ N1 檢定攻頂）**：內建 N5 至 N1 分級 SRS 間隔重複單字閃卡、核心文法百科（含接續、語感與考點解析）與綜合模擬測驗。

---

## 核心功能

1. **🗺️ 6 階段零基礎到 N1 學習藍圖 (`Stage 0 ~ Stage 5`)**：
   - 自動追蹤每日學習經驗值 (`XP`)、連續學習天數 (`Streak`)、已熟記五十音、SRS 單字熟練度與已完成情境對話。
2. **🔤 五十音互動發音表（平假名・片假名・濁音・半濁音・拗音）**：
   - 點擊任一假名立即播放日語真人語音（Web Speech API `ja-JP`），並提供**零基礎字源圖像記憶口訣**與代表單字。
3. **💬 8 大真實情境對話模擬器 & 語音跟讀 (`Shadowing`)**：
   - 涵蓋：初次見面自我介紹、餐廳點餐結帳、車站問路搭車、藥妝購物免稅、飯店入住寄放行李、朋友週末邀約、藥局看診買藥、職場商務高階敬語（N3~N1）。
   - 支援 **🔊 正常語速 (1.0x)**、**🐢 慢速分解 (0.72x)**、**🔤 羅馬拼音開關** 與 **🎙️ 麥克風開口跟讀相似度評分**。
4. **🗂️ SRS 間隔重複單字閃卡 & JLPT N5~N1 文法百科**：
   - 依 **零基礎必背 / N5 / N4 / N3 / N2 / N1** 分級篩選。
   - Anki 風格 4 級記憶評分（忘記 / 模糊 / 記住 / 秒答），自動累計熟練度。
5. **🏆 綜合闖關測驗 & N1 檢定模擬考**：
   - 作答後自動朗讀日文原句並顯示完整文法與詞彙詳解。
6. **📱 手機 PWA 安裝與離線學習支援**：
   - iOS Safari 點擊「分享」➔「加入主畫面」，或 Android Chrome 點擊「安裝應用程式」，即可像原生 APP 一樣全螢幕隨身學習。
